**[ARADHYA](https://github.com/Saurabh0003M/ARADHYA)** — a local-first AI Operating Intelligence for Windows.

Every device-affecting action passes a **Hooks → Permissions → User Approval** gate with JSONL audit logging, plus a cloud-privacy gate that keeps sensitive data on local models.
