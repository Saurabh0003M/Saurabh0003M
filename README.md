### 🔭 Flagship project

**[ARADHYA](https://github.com/Saurabh0003M/ARADHYA)** — a local-first AI Operating Intelligence for Windows.

Runs **100% on-device** via Ollama, fully offline. A ReAct execution loop and intent router drive 50+ built-in tools across 15 categories, extensible through a zero-code Markdown skills framework. Every device-affecting action passes a **Hooks → Permissions → User Approval** gate with JSONL audit logging, plus a cloud-privacy gate that keeps sensitive data on local models. Three interfaces: Rich CLI, Tkinter desktop overlay, and a Telegram bot — with offline voice control via Faster-Whisper.

`Python` · `Ollama` · `SQLite` · `MCP` · 65 test files
